# Dasol Portfolio

현재 웹사이트의 GitHub Pages 업로드용 파일입니다.

## 파일
- index.html: 페이지 내용과 구조
- style.css: 글자, 색, 간격과 배치
- project-preview.js: 프로젝트 이미지 미리보기 동작
- assets/: 소개 사진과 프로젝트 이미지 5개

## 업로드
1. ZIP을 먼저 압축 해제합니다. ZIP 자체를 업로드하지 않습니다.
2. 압축 해제한 index.html, style.css, project-preview.js와 assets 폴더를 GitHub 저장소 최상위에 함께 업로드합니다.
3. 저장소 첫 화면에 index.html이 보이도록 합니다.
4. GitHub Pages의 배포 대상으로 업로드한 브랜치의 루트 폴더를 선택합니다.
5. 배포 후 발급된 주소에서 사진과 프로젝트 미리보기가 보이는지 확인합니다.

## 참고
- CSS 및 이미지 경로는 GitHub Pages 하위 경로에서도 사용할 수 있도록 상대 경로를 사용합니다.
- assets 폴더 이름과 이미지 파일 이름을 유지하세요.
- 현재 프로젝트 미리보기는 JavaScript를 사용합니다. HTML/CSS만 허용하는 과제라면 변경이 필요합니다.
- 경력 항목은 디자인 확인을 위해 작성한 예시입니다.
- 페이지의 전화번호, 이메일, 사진과 코드는 공개 저장소에 올리면 공개됩니다.
- index.html을 더블클릭하면 로컬에서도 확인할 수 있습니다.
